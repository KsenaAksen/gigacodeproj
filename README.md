# 🌟 Мой звёздный дневник

> Каждый день — новое приключение. Запиши, каким он был!

**«Мой звёздный дневник»** — это лёгкое клиентское веб-приложение для детей. Оно помогает отмечать ежедневное настроение, писать короткие заметки о прошедшем дне и получать за это звёздочки ⭐

Игровая форма делает рефлексию простой и приятной: ребёнок учится замечать свои эмоции, выстраивает полезную привычку и видит, как растёт его «звёздное небо».

## ✨ Основные возможности

- 😊 **Выбор настроения** — четыре понятных варианта с эмодзи: «Отлично», «Хорошо», «Нормально», «Грустно».
- 📝 **Короткие заметки** — необязательное текстовое поле, чтобы рассказать о самом интересном за день.
- ⭐ **Звёздочки за каждую запись** — за каждый сохранённый день ребёнок получает звезду.
- 📊 **Подсчёт прогресса** — на карточке «Мои звёздочки» отображаются:
  - количество дней с записями;
  - количество заработанных звёзд;
  - **серия** — сколько дней подряд ведётся дневник (серия не прерывается, если сегодняшний день ещё не заполнен, но вчерашний был).
- 📖 **История записей** — все воспоминания хранятся списком: сверху самые новые, с датой, настроением и заметкой.
- 🗑️ **Удаление записей** — любую запись можно удалить из истории, статистика обновится сразу.
- 💾 **Сохранение в `localStorage`** — данные остаются в браузере после перезагрузки страницы, сервер и регистрация не нужны.
- 💬 **Дружелюбные подсказки** — мягкие всплывающие сообщения (например, если забыли выбрать настроение или хранилище браузера недоступно).
- ♿ **Доступность** — семантическая разметка, атрибуты `aria-*`, поддержка `prefers-reduced-motion`.
- 📱 **Адаптивный дизайн** — удобно пользоваться и на компьютере, и на телефоне.

## 🛠️ Используемый стек

| Технология | Для чего используется |
|---|---|
| **HTML5** | Семантическая разметка страницы, элемент `<dialog>` для уведомлений |
| **CSS3** | Оформление в «космической» тёмной теме, CSS-переменные, адаптивная вёрстка |
| **Vanilla JavaScript** | Вся логика приложения: настроение, записи, статистика, история |
| **localStorage** | Хранение записей прямо в браузере |

Проект написан **без фреймворков, библиотек и сборщиков** — никаких зависимостей и `npm install`.

## 🚀 Как запустить проект локально

Сборка и установка не нужны — приложение работает прямо из файлов.

**Вариант 1. Просто открыть файл** 🖱️

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/KsenaAksen/gigacodeproj.git
   cd gigacodeproj
   ```
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari) двойным кликом.

**Вариант 2. Через Live Server в VS Code** ⚡

1. Откройте папку проекта в Visual Studio Code.
2. Установите расширение **Live Server**.
3. Нажмите правой кнопкой на `index.html` → **Open with Live Server**.

Страница откроется в браузере и будет автоматически обновляться при изменении файлов.

## 💡 Как пользоваться

1. 🌙 Выберите настроение, нажав на одну из эмодзи-кнопок.
2. ✍️ При желании напишите пару слов о своём дне.
3. ⭐ Нажмите **«Сохранить день»** — запись появится в истории, а звёздочек станет больше.
4. 🏆 Заходите каждый день, чтобы увеличивать серию!

---

## 🔒 О данных

Все записи хранятся **только в вашем браузере** (ключ `my-star-diary.entries.v1` в `localStorage`) и никуда не отправляются. Если очистить данные сайта или сменить браузер, записи пропадут.
